# طلاز — نسخه‌های رسمی ویندوز

این مخزن فقط برای انتشار فایل‌های نصب و به‌روزرسانی طلاز است. سورس برنامه در مخزن جداگانه نگه‌داری می‌شود.

[مشاهدهٔ آخرین نسخه و تغییرات](https://github.com/amin-tm/Talaz-app-release/releases/latest)

[دریافت نصب‌کنندهٔ آخرین نسخه](https://github.com/amin-tm/Talaz-app-release/releases/latest/download/Talaz-Setup-Windows.exe)

فایل نصب پس از نخستین انتشار در دسترس قرار می‌گیرد. در صفحهٔ هر نسخه، نصب‌کننده، اجرای مستقل، راهنمای فارسی و فایل `SHA256SUMS.txt` برای بررسی صحت دانلود ارائه می‌شوند.

## نصب

فایل `Talaz-Setup-Windows.exe` را اجرا کنید و مراحل فارسی نصب، انتخاب پوشه و ساخت میانبر را دنبال کنید. برنامه برای شروع، اعتبار حساب را آنلاین بررسی می‌کند و حساب تازه با پکیج رایگان تعیین‌شده از سوی سرور شروع می‌شود.

## به‌روزرسانی

ابتدا کار باز را با پسوند `.talaz` ذخیره و برنامه را ببندید. سپس نصب‌کنندهٔ نسخهٔ تازه را اجرا کنید. بخش «به‌روزرسانی برنامه» در نوار کناری نیز نسخهٔ جدید را خودکار و دستی از همین مخزن بررسی می‌کند.

این بسته از Edge یا Chrome موجود روی سیستم استفاده می‌کند و موتور مرورگر را همراه ندارد. برای Windows 7 موتور سازگار لازم است و اجرای همهٔ امکانات روی آن در این تحویل تأیید نشده است.
